Connexion à la base partagée (Firebase)

Nécessaire une seule fois pour que les votes de tout le monde se retrouvent au même endroit. Voir comment récupérer ces informations
1. Va sur console.firebase.google.com, crée un projet (gratuit, sans carte bancaire).
2. Dans le projet : Firestore Database → Créer une base → mode production, choisis une région proche.
3. Dans Règles de Firestore, remplace le contenu par :
rules_version = '2'; service cloud.firestore { match /databases/{database}/documents { match /soirees/{eventId} { allow read, write: if true; } match /appdata/{docId} { allow read: if true; allow write: if request.auth != null && request.auth.uid == 'TON_UID_ICI'; } } } 4. Dans Paramètres du projet (icône engrenage) → onglet Général → section "Vos applications" → clique l'icône Web (</>) → donne un nom → copie les valeurs affichées ci-dessous.
